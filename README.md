# To-Do List App

A simple to-do list web app built to practice core JavaScript, DOM manipulation, and event handling.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Live clock display

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Live Demo
https://to-do-app-six-pearl.vercel.app/

## What I Learned
- DOM manipulation and event handling
- Structuring a small project from scratch
- Writing clean, readable JavaScript

## Future Improvements
- Add local storage so tasks persist after refresh
- Add task categories or priority levels
- Migrate to React for state management
